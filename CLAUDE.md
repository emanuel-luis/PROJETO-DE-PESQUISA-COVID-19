# covid19-xray-pipeline

DVC pipeline for chest X-ray COVID-19 vs normal classification. Package `covidxr`, Python 3.12, uv.

## Commands

- `make install` / `make install-cnn`: locked sync, without / with torch (`install-cnn` pulls ~3 GB of CUDA wheels on Windows; never run it casually).
- `make lint`: ruff check, ruff format --check, mypy strict on `src`. CI runs the same target.
- `make test`: `uv run pytest -m "not external and not gpu"` (includes slow end-to-end tests). `make test-fast` runs the default selection.
- `make demo`: whole pipeline on synthetic images in `.demo/`. `make pipeline`: `dvc repro` on real sources plus `covidxr report`.
- `uv lock --check` must pass after any dependency change.

## Repo map

- `src/covidxr/`: one module per stage (`catalog`, `process`, `features`, `split`, `evaluate`, `report`), `ingest.py` plus `sources/` adapters, `training/{baseline,cnn}.py`, `contracts.py` (pyarrow schemas), `layout.py` (every path), `runmeta.py` (`_run.json`), `io.py` (atomic writes), `config.py` (params loading and `params_hash`), `cli.py`.
- `dvc.yaml` and `params.yaml` define the DAG; `params.ci.yaml` is the synthetic profile used by CI and `make demo`.
- `docs/DATA.md` (data contract), `docs/DECISIONS.md` (decision log), `docs/REFACTOR_PLAN.md` (plan).
- `notebooks/legacy/`: the 2022 notebook, unchanged.

## Invariants

- A stage writes into a temporary directory and swaps it in atomically (`replace_dir`, `staged_dir`, `atomic_path`); `_run.json` is written last, so a directory without it is incomplete.
- Tables are deterministic: sorted, no timestamps, fixed seeds. `reports/quality.json` and `reports/metrics.json` change only when results change.
- Every table goes through `validate()` against its contract; unusable rows go to `rejects.parquet` with a reason from `REJECT_REASONS`.
- Parameters that never change output (`workers`, `n_jobs`, `num_workers`) stay out of `params_hash` and out of the DVC `params:` of their stage.
- Splits are group-aware; scalers are fitted on train only; the test split is never used for selection; threshold is fixed.
- CI never downloads real data or uses Kaggle credentials; external and gpu tests are deselected.
- No secrets in the repo. Kaggle credentials are only checked for presence, never read or logged. Images and derived data (`data/`, `models/`) never enter git.
- `training/cnn.py` imports torch inside functions only; the code must import and mypy-pass without the cnn extra.
- CNN checkpoints live in `data/.cache/cnn/<key>/last.pt` (not a DVC out). The key is a `params_hash` of seed, train_cnn params without `num_workers`, device type and sha256 of splits, processed table and `data/processed/_run.json`.
- Actions are pinned by full SHA with a version comment; workflows use least-privilege `permissions`, `persist-credentials: false` and `timeout-minutes`.

## Conventions

- English for code, docs and commits; Conventional Commits; plain prose, no em dashes.
- ruff line length 100 with the `BLE` rule (a broad `except` needs `# noqa: BLE001 - reason`); mypy strict.
- Reuse `covidxr.io`, `layout.Layout` and `runmeta.stage_run` in a new stage; add its params to `config.py`, its contract to `contracts.py`, and a row in `docs/DECISIONS.md` for any non-obvious choice.
- The README results block between the `covidxr:metrics` markers is generated by `covidxr report`; do not edit it by hand.
